# Aura IDE как настольное приложение (ярлык на рабочем столе + обновления)

Сейчас вы запускаете редактор из терминала (`./scripts/code.sh`). Aura IDE — это
форк VS Code, а значит его можно собрать в обычное настольное приложение
(Electron), которое запускается по двойному клику на иконке, как любое другое.

## Linux

```bash
./scripts/install-desktop.sh
```

Скрипт:
1. собирает приложение (`npm run gulp vscode-linux-x64`);
2. ставит его в `~/.local/share/aura-ide`;
3. создаёт ярлык `Aura IDE` в меню приложений и на рабочем столе.

После этого просто кликаете по иконке — приложение открывается как обычное окно.

## Windows

```bat
scripts\install-desktop.bat
```

Собирает `vscode-win32-x64` и создаёт ярлык «Aura IDE» на рабочем столе
(устанавливается в `%LOCALAPPDATA%\Programs\AuraIDE`).

## Обновления

Есть два механизма:

1. **Скрипт обновления** (рекомендуется): `./scripts/update-aura.sh` — делает
   `git pull` из main, переустанавливает зависимости, пересобирает и
   переустанавливает приложение. Настройки хранятся отдельно и не теряются.

2. **Встроенный авто-апдейт** (как в VS Code): в `product.json` задан
   `updateUrl`. Чтобы кнопка «Проверить обновления» в редакторе работала,
   нужен сервер обновлений, совместимый с API VS Code
   (`GET /api/update/{platform}/{quality}/{commit}`), который отдаёт новый
   архив и версию. Для самостоятельного хостинга можно использовать
   [open-vsx](https://open-vsx.org) или поднять простой сервер, отдающий
   собранные релизы из GitHub-релизов репозитория. Без такого сервера
   встроенный апдейт просто сообщает «нет обновлений», а обновляться нужно
   скриптом `update-aura.sh`.

## Что это значит

- Икон на рабочем стеле — да, после `install-desktop.sh` / `install-desktop.bat`.
- Изменения «туда шли» — да: это обычный git-репозиторий; `git pull` + пересборка
  (скрипт `update-aura.sh`) доставляет новые версии.
- Полноценный авто-апдейт «по кнопке» — возможен, но требует сервера обновлений
  (см. выше).
