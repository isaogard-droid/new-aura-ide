# DeepSeek Harness: нейронка запустила агентскую среду — самый быстрорастущий репозиторий GitHub

Пост из канала (текст как есть):

> Создаём ИИ-агентов из воздуха с DeepSeek: нейронка запустила агентскую среду Harness и теперь это самый быстрорастущий репозиторий на Гитхабе!
>
> За трое суток больше 130 000 звёзд! Во многом это благодаря такой фиче: плагином может быть ВСЁ. Модели, сессии, скиллы, песочницы и даже интерфейс. Отдаёте Harness всё, а он отдаст агента.
>
> 🔅 У среды своя архитектура на Cordis, которая позволяет менять компоненты;
> 🔅 Схема простая: любая модель + любой компонент = готовый агент;
> 🔅 Сработает вообще с ЛЮБЫМИ компонентами.
>
> Плюсом сообщество сделало 6️⃣0️⃣0️⃣0️⃣ готовых скиллов для DeepSeek Harness. Скачать их можно тут. (https://github.com/topics/dsh-plugin)
>
> Установка тулзы: кидаем в терминал команды по порядку так —
> git clone
> https://github.com/deepseek-ai/deepseek-harness
> cd
> deepseek-harness
> pnpm install
> pnpm run build
> pnpm dsh web
>
> БЕСПЛАТНЫЕ ИИ-агенты из чего угодно — тут. (https://deepseek.com/harness/en/)

## Контекст (проверено через Camoufox 17.08.2026)

- **Репо живьём**: github.com/deepseek-ai/deepseek-harness — на момент
  проверки **140k звёзд**, 14.2k форков, 12 293 коммита, MIT-лицензия,
  TypeScript (pnpm, монорепо packages/apps/native/python/website).
- **Числа поста близки к правде**: обзоры фиксируют 90k звёзд за двое
  суток (justin3go, 15.08) и 95k за двое суток (flowtivity) — «130k за
  трое суток» маркетинговая прибавка, но порядок верный.
- **Топик dsh-plugin**: 6 048 публичных репозиториев — «6000 готовых
  скиллов» подтверждается (в топе — nexu-io/open-design, 87.8k звёзд,
  дизайн-плагин, «Claude Design alternative», BYOK для 20+ CLI).
- **Официальный сайт**: deepseek.com/harness/en/ — developer preview,
  слоган «Everything is a plugin».
- **Архитектура**: Cordis 4.0.1 + cosmokit вендорятся в репо; в корне
  свои AGENTS.md/CLAUDE.md (среда сама управляется агентами — рекурсия).
- **Зачем это AGGG2.0**: конкурент/референс для нашей прошивки правил —
  у них «плагин = всё» (модели, сессии, скиллы, песочницы, UI), у нас
  прошивка-ядро поверх харнесов. Смотреть как эталон экосистемы
  скиллов и скорость принятия сообществом.
