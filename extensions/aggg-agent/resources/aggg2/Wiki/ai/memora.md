# Memora — долгосрочная память для Codex и Claude Code

Оригинальный пост:

Агенты перестали забывать всё после перезапуска.

Memora добавляет Codex и Claude Code долгосрочную память: сохраняет задачи, баги, документы и важный контекст, а потом сама находит нужные воспоминания в новых сессиях.

Память можно даже изучать через интерактивный граф. Забираем здесь (https://github.com/agentic-box/memora).

- Фича: интерактивный граф памяти для изучения.

## Дополнительный пост (повторный, тот же инструмент)

ИИ-агентам прикрутили почти ВЕЧНУЮ память — разрабы собрали (https://github.com/agentic-box/memora) опенсорсную тулзу Memora, которая сохраняет работу Codex и Claude Code между сессиями.
