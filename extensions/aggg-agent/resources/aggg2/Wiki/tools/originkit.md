# Originkit — бесплатная библиотека анимаций и компонентов для сайтов

Оригинальный пост:

Вэб-дизайнеры, забираем огромную, БЕСПЛАТНУЮ библиотеку анимаций и компонентов интерфейса для сайтов — Originkit.

Внутри — куча элементов, чтобы сделать из проекта конфету: от текста до курсора и фона. Всё максимально настраиваемое — делайте ярлык под себя, копируйте код и вшивайте в сайт.

Все элементы совместимы с React/Framer — можно вносить даже в уже готовые проекты. Также их возможно интегрировать в Claude Code или Codex.
