# Speed-Test — измерение скорости сети в браузере без установки

Оригинальный пост:

Speed-Test - бесплатный и открытый HTML5-инструмент для оценки производительности сети, написанный на чистом JavaScript и использующий только встроенные веб-API, такие как XMLHttpRequest (XHR), HTML, CSS, JS и SVG.
