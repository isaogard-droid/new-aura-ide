# Little Big Mouse — курсор не теряется между мониторами

Оригинальный пост:

Little Big Mouse — мышь, которая не теряется между мониторами

Если рядом стоят мониторы с разным разрешением или разной диагональю, курсор при переходе между ними ведёт себя странно. Он «прыгает» вверх или вниз, потому что Windows считает экраны в пикселях, а не в сантиметрах.

Little Big Mouse (https://littlebigmouse.mgth.fr/) чинит именно это. Программа выстраивает виртуальную карту экранов с учётом их физического размера и плотности пикселей, и курсор переходит с 4K-монитора на Full HD ровно в той точке, где вы его подвели к краю.
Дополнительно можно настроить «сопротивление» на границах экранов, чтобы курсор не проскакивал на соседний монитор случайно — причём отдельными участками вдоль края и с разными настройками для простого перемещения и для перетаскивания окна. Изменения применяются на лету, так что раскладку можно пощупать до сохранения.

Есть и спасательный сценарий: если конфигурация загнала курсор туда, откуда его не вытащить, зажатие Ctrl + Alt + Shift + M возвращает мышь обратно. Сочетание при желании меняется в настройках.

Поддерживаются Windows 10 и 11, для Linux есть экспериментальная сборка.

## Контекст

- Пост готовый, ссылка не проверялась (по указанию автора).
- Что: решение проблемы «прыгающего» курсора между мониторами с разной физикой (разрешение/диагональ): виртуальная карта экранов в физических размерах и плотности пикселей.
- Возможности из поста: сопротивление на границах (участками, отдельно для перемещения/перетаскивания); live-применение изменений; «спасательный» Ctrl+Alt+Shift+M (возврат мыши); Windows 10/11, Linux — экспериментально.

## Вывод

Точечная, но очень человеческая боль: мульти-монитор с разными панелями. Полезно всем с 4K+Full HD связками. Паттерн «виртуальная карта в физических единицах» — наглядно, почему пиксельная модель Windows не годится. Простая утилита, закрывающая конкретную проблему — KISS в действии.
