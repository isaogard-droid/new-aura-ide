# CLI Anything — переносим любой софт в терминал для агентов

Вайбкодим в ЛЮБОЙ программе

Нашли топовый инструмент CLI Anything, позволяющий переносить софт в терминал.

Теперь можно прикрутить Claude или Codex для огромного количества задач: от создания презентаций до разработки игр.

Забираем БЕСПЛАТНО – тут (https://github.com/HKUDS/CLI-Anything).

## Контекст

- Пост готовый, ссылка не проверялась (по указанию автора).
- Что: инструмент, дающий GUI-софту CLI-интерфейс — чтобы агенты (Claude, Codex) могли управлять программами из терминала.
- Кейсы из поста: создание презентаций, разработка игр и др.

## Вывод

Идея в духе desktop-harness: дать агенту доступ к приложениям, но не через GUI-эмуляцию, а через CLI-обёртки — надёжнее и быстрее (структура вместо пикселей). Для нас актуально: если инструмент позволяет обернуть любое приложение в CLI — это расширяет возможности агентной автоматизации.
