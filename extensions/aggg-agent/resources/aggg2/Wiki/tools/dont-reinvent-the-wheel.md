# dont-reinvent-the-wheel (reuse-before-build) — скилл-на-полке

Референс внешнего скилла для AI-агентов. Решено НЕ поднимать в пул
`skills/` — причины ниже (разбор 17.08.2026, research.db id=788).

## Что это

Крошечный drop-in SKILL.md (агентские харнесы: Claude Code, Codex и др.).
Цель одна: перед написанием своего кода агент обязан проверить зрелые
существующие решения — open-source проект, коммерческий продукт,
официальный API, внутренний инструмент или стандартная библиотека
экосистемы.

Правило скилла: «предпочитай самое простое достаточное зрелое решение;
пиши свой код только если переиспользование/адаптация/покупка не
подходят». Триггер — старт любой работы, которая может дублировать
существующее (фичи, тулзы, библиотеки, интеграции, сервисы, UI).

## Почему НЕ в пуле скиллов AGGG2.0

- Принцип уже вшит на трёх уровнях (17.08.2026): `harness/core.txt` п.5б
  («ХАРДКОД-СПИСКИ/ВЕЛОСИПЕДЫ ДЛЯ РЕШЁННОГО — НЕ ПИСАТЬ», инжектится
  каждый ход), AGENTS.md («Хардкод-списки и свои велосипеды для
  решённого — не пишем»), CLAUDE.md («Сначала смотри, что уже есть»).
- Тот же класс задач закрывает скилл `production-first-decisions`
  (продакшен-первым: веб-ресёрч как в индустрии → сверь гипотезу →
  делай).
- Цена лишнего скилла в пуле — токены триггера и проверок на каждый ход
  (правило docs/canon/WIKI.md) + адаптация (перевод, водяной знак, trigger-эвалы).

## Кейс, ради которого это актуально

17.08.2026: в search.py зашит наивный список русских окончаний вместо
стеммера Snowball Russian — готовое решение индустрии (Elasticsearch/
Lucene) покрывало глаголы, которых в списке не было. Исправлено
вендором snowballstemmer (research.db id=786). Канон-правило написано
по этому кейсу (id=788).

## Что взять из скилла (уже взято)

1. Чек-шаг ПЕРЕД постройкой: «существует ли зрелое решение этой задачи?»
2. Классы готового, которые проверяются: open-source, продукт, официальный
   API, внутренний инструмент, стандартная библиотека.
3. Свой код — только когда переиспользование/адаптация/покупка не
   подходят.
