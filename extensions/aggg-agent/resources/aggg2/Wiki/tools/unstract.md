# Unstract — LLM-экстрактор документов в структурированный JSON

Оригинальный пост:

Ему можно скормить:
• PDF-файл
• Инвойс (счет на оплату)
• KYC-анкету
• Банковскую выписку
• Налоговую декларацию

А на выходе вы получите чистый JSON, полностью готовый к загрузке в вашу базу данных.

Забудьте про:
❌ Бесконечные регулярки (regex)
❌ Шаблоны под каждого отдельного поставщика
❌ Обучение моделей под каждый новый формат

Вам больше не придется писать уникальный экстрактор под каждый тип документа.

Просто опишите текстом на обычном языке, какие данные вам нужны.

Unstract сам подключит LLM и вытащит нужные поля, даже если структура документа изменится.

Что он умеет:
→ Извлекать структурированный JSON из PDF, сканов и картинок.
→ Создавать схемы парсинга обычными промптами на английском через Prompt Studio.
→ Разворачиваться как REST API или ETL-пайплайн за считанные минуты.
→ Интегрироваться с Claude и другими агентами через протокол MCP.
→ Загружать данные в S3, GCS, Snowflake, BigQuery, Postgres и другие базы.
→ Работать на базе OpenAI, Anthropic, Bedrock, Gemini, Mistral, Ollama и других провайдеров.
