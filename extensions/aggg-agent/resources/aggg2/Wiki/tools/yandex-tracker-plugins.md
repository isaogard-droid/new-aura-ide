# Яндекс 360 Трекер — платформа плагинов с вайбкодингом

Оригинальный пост:

Тулзу для кастомизации Трекера выпустил Яндекс 360 — это платформа плагинов с возможностью вайбкодинга.

Внутри:
🔅 Готовые плагины из каталога. Ставим в один клик;
🔅 Любой плагин можно вайбкодить на ЛЮБОЙ нейронке на стороне юзера;
🔅 Результат виден сразу в интерфейсе, а правки вносятся в реальном времени;
🔅 Плагин видит только те данные, к которым есть доступ у юзера — права контролит админ.

Например, можно сделать плагин учёта времени, который посчитает потраченное на задачу время и сформирует отчёт.
