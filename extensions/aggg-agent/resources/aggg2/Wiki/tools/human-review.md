# human-review — фидбэк ИИ-агентам в готовых файлах, как в Google Docs

Оригинальный пост:

🌟 Оставить фидбэк ИИ-агентам теперь можно прямо в готовых файлах — новый скилл human-review даёт HTML и Markdown интерфейс, как в Google Docs.

• Справа можно оставить комментарии, а слева — увидеть превью страницы и выделить ошибки.
• Можно внести правки, поменять форматирование и двигать картинки.
• В один клик можно добавить или удалить любые элементы интерфейса.
• Все комментарии отправляются агенту одним батчем вместо бесконечного общения в чате.
• Работает локально на компьютере без отправки данных в облако.

Скилл пригодится всем, кто создаёт сайты, лендинги, интерфейсы, длинные тексты, презентации и многое другое.

Пробуем — тут (https://github.com/petergyang/human-review).

## Вывод

human-review решает больную точку итераций «агент → человек → агент»: пакетный фидбэк в одном месте вместо бесконечных мелких правок в чате. Паттерн «батч-ревью» сильно экономит и токены, и нервы. Логичное дополнение к связке «агент генерит → человек ревьюит» (ср. Changes Walkthrough у OpenChamber).
