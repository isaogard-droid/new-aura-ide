Оригинальный пост:

DrawDB -это браузерный инструмент для визуального проектирования баз данных. Он позволяет быстро набросать схему данных (ER-диаграмму), связать таблицы и в один клик сгенерировать готовый SQL-скрипт.

Ключевые возможности
• Визуальный конструктор схем: вы можете таблицы, добавлять поля, указывать типы данных и настраивать связи в несколько кликов мыши.

• Генерация SQL и миграций: инструмент автоматически преобразует графическую схему в валидный SQL-код или файлы миграций для создания таблиц.

• Широкая поддержка СУБД: проект поддерживает работу со множеством популярных баз данных, среди которых PostgreSQL, MySQL, MariaDB, SQLite, Oracle и SQL Server.

• Импорт и экспорт: разработанные диаграммы можно экспортировать в виде SQL-скриптов или картинок (SVG/PNG), а также загружать обратно готовые скрипты для автоматической сборки схем.
