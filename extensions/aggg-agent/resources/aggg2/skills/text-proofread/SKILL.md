# Text proofread: вычитка без потери смысла

Убирать ТОЛЬКО ошибки, не трогая смысл, слова и голос автора. Правка механики, не редактура: вычитка — сервис, не навязывание вкуса.

## When to use / NOT

**Use:** «исправь текст без ошибок», «вычитай», «проверь грамматику» — пост, письмо, заметка, на языке оригинала.
**NOT use:** рерайт/копирайтинг, перевод, «сделай красивее/продающее», humanizer, код и конфиги (линтеры / `lsp-code-depth`).

## Workflow

1. **Отдели команду от текста.** Просьба-команда («исправь тест щас») — НЕ часть текста: не редактируй и не включай в результат. (Грабля 19.08.)
2. **Язык и регистр — из самого текста**, не спрашивай; сомнение — одно уточнение.
3. **Пасс 1 — корректность (напрямую).** Орфография; слова-перевёртыши — по КОНТЕКСТУ («тест» vs «текст»); согласование и падежи (русский); обязательные запятые («что/который», обособления); пробелы, двойные знаки; типографика: «ёлочки», тире «—», дефисы.
4. **Пасс 2 — пунктуация и механика.** Заглавные, точки, списки, прямая речь. Только объективное.
5. **Пасс 3 — «и в целом» (ТОЛЬКО по явному запросу).** Ясность/лаконичность, НЕ меняя смысл и голос. Без запроса — не трогать (авторский стиль не дефект).
6. **Выдай:** (а) исправленный текст целиком первым; (б) список правок: «применено» (объективные) + «предложения» (вкус — автор решает). Вкус молча не применять.

## Success criteria

- Смысл и слова автора сохранены (дословное сравнение, кроме списка правок); минимальные замены, не перефразирование.
- Исправлены только ошибки; ничего не добавлено/не убрано по вкусу; команда не отредактирована и не в тексте.

## Failure modes / Gotchas

- **Переписал стиль** — «улучшил» без запроса; симптом: правок больше, чем ошибок.
- **Отредактировал команду** (грабля 19.08).
- **Гиперкоррекция** — исправил авторский приём («щас», ритм); сомнение — в «предложения».
- **Потерял смысл** — «синоним» с другим оттенком: не знаешь оттенка — не трогай.
- **Угадал двусмысленность** — аннотируй оба чтения или спроси одним вопросом.
- **ё/е:** сохранить выбор автора; смешано — выровнять к преобладающему, отметить.
- **Типографика:** «ёлочки» снаружи, „лапки" внутри; тире «—» с пробелами; дефис ≠ тире.
- **Числа, даты, никнеймы, ссылки:** не трогать без ошибки внутри.
- Код/команды/конфиги не вычитывать.
- Паттерн индустрии: Cardinal Rule «preserve meaning» + Fix vs Suggest + multi-pass (JayRHa/AgentSkills, awesome-ai-agent-skills).
