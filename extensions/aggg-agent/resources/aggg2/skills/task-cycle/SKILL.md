# Task cycle: повторяемый цикл любой задачи

Первоисточник: `CYCLE.md` (fable-loop PLAN→EXECUTE→VERIFY→AUDIT + канон). Любая задача — один виток; фазы повторяются КАЖДЫЙ раз, «в прошлый раз помню» не считается.

## Workflow (9 фаз — в этом порядке)

0. **Саммари запроса** (задача + цель). Не сходится с буквой → уточнить ДО действий.
1. **База — сначала.** `findings.py search` + `search.py`. Память сессии — НЕ источник (ядро: core.txt п.2).
2. **Веб-ресёрч — первое действие.** Camoufox: поиск → первоисточники → клики (ядро: core.txt п.1; детали — `web-research-camoufox`). Ресёрч — до конца задачи.
3. **План — для нетривиального.** Критерий готовности, что делаем, что НЕ делаем, риски. Мелочь — без плана.
4. **Действие.** Нет базы — `build.py`, свежесть — `search.py --refresh`; код ЧЕРЕЗ базу (`db-first-search`), глубина — agent-lsp, ревью — code-review-graph. Сначала смотри, что уже есть (scripts/, db-tools/) — не изобретай велосипед.
5. **Проверка — обязательно.** Линтер + семгреп + тесты + CI + живьём. Доступность сайтов — через Camoufox, не curl. «Собралось» ≠ «работает».
6. **Находки — в research.db**: `findings.py add` (что выбрали, почему, что отвергли, ссылки).
7. **Документирование.** Код → CHANGELOG. Повторилась ошибка → правило в канон. Опыт → скилл.
8. **Отчёт.** Результат первым, честные оговорки. Объяснять — как динозавру (ядро: core.txt п.7; паттерны — `aggg2-persona`).

## Гейты (переходы между фазами)

- **Тривиально** — фазы 3-7 свёрнуто: сделал → одна проверка → отчёт в двух фразах.
- **Не знаю / не уверен** — вернуться на фазу 2, не угадывать.
- **Ошибка 2 раза** — сменить метод, получить НОВЫЙ факт (лог, дамп, изоляция), не правка вслепую.
- **Необратимое / наружу / платно** — явное подтверждение пользователя.
- **Затык >3 циклов** — остановиться, postmortem, правило из разбора — в канон.

## Циклы вокруг

- **Установка:** `setup.py` → `run_tests.sh --mirrors` (детали — `workspace-setup`).
- **Ревью:** дифф → CRG (impact) → agent-lsp → dead-code проверка → тесты.
- **Ошибок:** грабля → причина → правило в канон → следующая задача уже с ним.

## Чеклист перед «готово»

- [ ] саммари сходится с буквой запроса
- [ ] база проверена (findings/search)
- [ ] ресёрч сделан ДО кода (нетривиальное)
- [ ] критерий готовности был/понятен
- [ ] проверка: линтер + тесты + живьём
- [ ] находки записаны (findings.py add)
- [ ] отчёт: результат первым

## Этапы (handoff)

- **Вход из:** `aggg2-mandatory-reads`, любая задача
- **Дальше:** по фазе: `db-first-search` → `skill-search` → `web-research-camoufox` → `fable-method`/`fable-loop` → `fable-judge`
