# Боевое крещение: стресс-тест с цифрами

Система не «работает» — она работает на N%. «Гарантированно» — замеренная цифра, не ощущение. Алгоритм: найти цифры → разобрать отказы → добить до максимума → отчёт результатом первым.

## Принципы (AGI-автономность)

- **Знаю, как делают другие** — чужие скиллы (`skills_search.py` --read/--tree) и камуфокс-паттерны индустрии ДО решения; своя догадка — после чужих (минимум 10 источников).
- **Ищу выход, не сдаюсь** — отказ = точка входа в цикл: реверс → новый угол → фикс → перезамер. Застрял 2 раза → смени метод, получи НОВЫЙ факт.
- **По цифрам, из текущей И будущей** — было X% + прогноз Y% → шаг с лучшим прирост/цена; перезамер подтверждает/опровергает.
- **Минимальная цена шага** — «дёшево → дорого» (кэш сначала); фикс от причины, не симптома; не переусложнять ради 100% (мусор источника ≠ наш баг — честный ответ дешевле хрупкой логики).

## Workflow

1. **Гипотеза и критерий** — что тестируем, какой % = успех; критерий видимый.
2. **Замер ДО (baseline)** — N ≥ 20-50 попыток (минимум 10), честно, с отказами: «было X/N = Y%». Внешние API — паузы между вызовами (троттлинг искажает).
3. **Реверс каждого отказа** — (а) наш баг → чиним; (б) внешнее (rate-limit, битые данные) → тип фиксируем; (в) артефакт теста → фиксируем.
4. **Фиксы от причин** — один отказ = одна причина = один фикс; перезамер ТЕМ ЖЕ набором.
5. **Перезамер ПОСЛЕ** — та же N: «было X% → стало Y%».
6. **Добить до 100% возможных** — страховки (фоллбэки, retry, кэш). Мусор источника → не наш баг: честный ответ + подсказка замены.
7. **Цифры в отчёт, урок в канон** — результат первым, таблица, причины остатка; урок → core.txt/доки/скиллы/CHANGELOG/findings.

## Пример (реальный, AGGG2.0, 18.08.2026)

Чтение 25 скиллов с каталогов: 10/25=40% → реверс (структура репо → tree-фоллбэк; рассинхрон id → fuzzy-поиск; rate-limit GitHub → кэш дерева 6ч) → 23/25 → страховка камуфокс-воркером (читает битые raw-пути, честное «Did you mean») → 49/50=98% чтения, 100% с ответом, 0 отказов. Урок: многоуровневое чтение (raw → tree → fuzzy → страница каталога → честный отказ).

## Поверхности батла (какой раннер под какой слой)

Агент-пирамида (ресёрч 19.08, 20 источников): детерминированное — юнитами, недетерминированное — условиями (condition-based waiting), живые прогоны — батлом с цифрами.

| Поверхность | Инструмент | Что батлит | Ключевой паттерн |
|---|---|---|---|
| GUI | `gui_battle.py` + `gui-battle-test` | кнопки/состояния кликами | evaluate_js-мост, Xvfb/XWayland |
| CLI | `cli_battle.py` | exit/stdout/stderr + таймауты | ISTQB; wait_retry — поллинг до условия |
| API | `api_battle.py` | статус-коды, схема, POST/идемпотентность | контракт: schema-типы, не наличие |
| Сервисы (systemd) | `cli_battle.py` + `systemctl show --value` | active/substate, перезапуски | show -p ActiveState --value |
| Хаос | `cli_battle.py` + методика | отказы сети/сервиса/диска/CPU | steady state → inject → замер |
| LLM-эвалы | `trigger_queries.json` + eval | триггеры/промпты | promptfoo: детерминированные первыми |
| Юниты | testing-discipline | логика без I/O | быстрый слой, батл не нужен |

**Мгновенно и без зависаний** (ядро `battle_core.py`): условие, а не sleep; шаг завершается, когда условие истинно; таймаут-убийца; MCP `battle`: battle_run(surface=…) НЕ блокирует (сразу log_path), battle_status — прогресс по логу.

**Хаос-минимум** (Netflix Chaos): 1) steady state — норма; 2) гипотеза «переживёт X»; 3) inject минимального отказа; 4) observe отклонение цифрами; 5) fix → повтор. Прод — только с согласия владельца; серьёзный хаос — Litmus, Chaos Monkey.

## Success criteria

- Цифра «было X% → стало Y%» (baseline и перезамер тем же набором)
- Каждый отказ разобран по причине; остаток — 0 или честно классифицирован (мусор источника) с подсказкой замены
- Урок записан: CHANGELOG + findings + канон

## Failure modes

- **Тест без пауз** — API троттлят серию (5 тем подряд → skills.sh замолчал): паузы 0.5-1.5с
- **Regex-артефакты** — id вне класса символов (`react:components`) выпадают: смотреть выборку глазами до реверса
- **Замер на кэше** — повтор = мгновенно из кэша: первый прогон после чистки — истина; кэш — отдельная цифра
- **«До 100% любой ценой»** — мусор источника чинить системой = переусложнение: честный отказ + подсказка + страховка браузером

## Gotchas

- Реверс ДО фикса: «не найден» = баг / rate-limit / битый id — чинятся по-разному
- Кэш — союзник и враг: TTL сутки камуфокс, 6ч дерево GitHub — повторы не «доказательство»
- Цифры с единицами: «98%» = 49/50 при N=50, 10 тем
- «100% с ответом» (чтение + честная подсказка) честнее «100% чтения»
