# Production-first: решения по индустрии, не из головы

Первоисточник: `CLAUDE.md` («ПРОДАКШЕН-ПЕРВЫМ», «ВЕБ-РЕСЁРЧ»). Источник истины — индустрия; знания — гипотезы, пока не проверены.

## Workflow

1. **Сформулируй «как это делают в проде?»** — явно, до действий.
2. **Web search** (Camoufox): 5-10 запросов с разных сторон — мануалы, официальные гайды, GitHub, статьи практиков, ADR. Первоисточники, не пересказы.
3. **Сверь СВОЮ гипотезу с найденным** — свои знания только предположение; «подумал» без поиска = догадка (ядро: core.txt п.1).
4. **Делай по индустрии.** Критерий: «так делают все, а не только я». Не подтверждено → гипотеза: проверь поиском до кода.

## Тест-перед-интеграцией (spike → ADR; SSW, Thoughtworks Tech Radar assess→trial→adopt)

1. **Вопрос:** что проверяем — функциональность, подходящесть под наш стек (русский код, размер/вес)?
2. **Замер в песочнице:** реальный кейс, сравнить с альтернативами И с «ничего не делать» (doing nothing — всегда вариант).
3. **Вывод — в research.db** (`findings.py add`).
4. **Интегрировать только после доказательства.** Проверено: CRG вошёл после замера, эмбеддинги отклонены расчётом стоимости.

## Глубина ресёрча — по задаче

- **Справка** — минимум 10 источников (ядро: core.txt п.1).
- **Решение/выбор** — ГЛУБОКИЙ ресёрч (`web-research-camoufox`): ширина (5-10 запросов параллельно) → глубина; эталонные репо, PR, issues, ADR; «так делают все» — измерять (сколько прод-проектов); итог = паттерн + почему победил + что отвергнуто. «Погуглил две статьи» = догадка.

## Три принципа решений (фильтр перед кодом)

- **DRY** — одна логика в одном месте; менять в 3+ файлах → общий источник.
- **KISS** — проще вариант, если закрывает задачу; сложность не «на будущее».
- **YAGNI** — не строить того, чего не просили; «а вдруг пригодится» — не основание.

Нарушение хотя бы одного без явной причины → пересмотреть, прежде чем писать.

## Дополнительные правила

- **Команды установки — из первоисточника** (npm/curl/winget/brew/bun/irm сверять с офиц. доками). Проверено: `opencode.ai/install.ps1` = 404, правильный метод — `npm i -g opencode-ai` (opencode.ai/download).
- **Сначала смотри, что уже есть:** `scripts/`, `db-tools/`, research.db, файлы проекта; **ресёрч — ДО, не после** (стандарты и первоисточники раньше правил/кода).

## Чеклист перед решением

- [ ] вопрос «как в проде?» сформулирован; 5-10 запросов с разных сторон, первоисточники
- [ ] гипотеза сверена с найденным; новый инструмент — замер в песочнице + doing nothing
- [ ] вывод в research.db (выбрали/отвергли/почему); итог = паттерн + почему победил + что отвергнуто
