# design-extract — копирование и разбор дизайна с референсов

Проверено живьём (kinogotv.cc → GUI-панель): точная копия стиля референса + «лучшее из индустрии». Модель не всегда видит картинки — цикл на ЧИСЛАХ (токены, computed styles, гистограммы пикселей), не «посмотрел и повторил».

## When to use / NOT to use

**Use:** референс задан сайтом/скриншотом; «сделай как там»; редизайн «в стиле»; дизайн-система чужого продукта; свой UI блёклый.

**NOT use:** дизайн с нуля без референса (ask-nodumb); верстка без образца; бэкенд.

## Workflow (пять фаз, в этом порядке)

### Фаза 1. Дизайн-ресёрч индустрии — ДО референса

Camoufox-поиск (web-research-camoufox): гайды тёмных тем, паттерны компонентов (segmented control, dashboard), сравнение технологий (SVG vs icon-font). 2+ источника на ключевое решение; выбор стека — глубже (CAMOUFOX.md).

### Фаза 2. Извлечение дизайн-системы референса (три слоя)

1. **CSS-файлы.** `curl -A "Mozilla/5.0" <сайт>` → grep `href="*.css"` → скачать. Токены: цвета, шрифты, радиусы, тени, размеры. `skills/design-extract/scripts/design_teardown.py css <css-файл>`. ⚠️ Бот-щит — см. Gotchas.
2. **Computed styles из ЖИВОГО браузера** (CSS ≠ рендер: медиа-запросы, :hover, JS). Camoufox/playwright → getComputedStyle с ключевых селекторов: backgroundColor, color, fontFamily, fontSize, fontWeight, borderRadius, borderColor, padding, boxShadow, textTransform. Сниппет — `references/browser-snippets.md`.
3. **Скриншот + гистограмма пикселей.** `design_teardown.py histogram <png> [-n 14]` → палитра: видны ли акценты, не ушёл ли рендер в монохром (только серые = не отрисовались).

Итог: **таблица дизайн-токенов** (`references/kinogo-case.md`): фон, слои, тексты, акценты, шрифты/размеры, радиусы, тени, паттерны компонентов.

### Фаза 3. Слияние: референс + лучшее из индустрии + платформа

- **Практики** из фазы 1 (анти-halation, focus-visible, placeholder, segmented control вместо select для 2-5 опций);
- **Платформа:** WebKitGTK+NVIDIA — нет backdrop-filter/blur/больших box-shadow (артефакты) → radial-gradient + бордеры/тени; `<select>` даёт нативный попап → сегмент-контрол;
- **НЕ копировать:** ассеты и код референса — только токены и паттерны. Иконки (напр. Font Awesome) → инлайн-SVG-спрайт в его стиле (линейный → Lucide 24x24 stroke 2 currentColor; SVG > icon-font в 2026).

### Фаза 4. Проверка пикселями, не глазами

1. Скриншот → гистограмма: акцентные цвета референса ДОЛЖНЫ появиться (сверка с таблицей). Только серые — чинить до приёмки.
2. E2E-смоук (окно живо, интеракции работают).
3. Сверка «деталь за деталью»: хедер, бейджи, подвал, иконки — что есть на референсе, чего нет у нас.

### Фаза 5. Итерация по фидбеку пользователя

«Не очень точно + не хватает иконок» = фаза, не замечание: второй проход глубже (computed styles, паттерны бейджей/иконок). Каждый проход — проверка гистограммой.

## Success criteria

- Таблица токенов извлечена (не «на глаз»); гистограмма содержит акценты референса.
- Каждый элемент референса имеет аналог — или осознанно отброшен с причиной.
- Фидбек закрыт вторым проходом с измеримой проверкой.

## Failure modes

| Симптом | Причина | Лечение |
|---|---|---|
| Гистограмма серая | рендер сломан (GPU) | убрать blur/backdrop-filter, проверить env |
| CSS ≠ реальный вид | бот-щит/JS/медиа | computed styles из живого браузера |
| «Не похоже» | поверхностное копирование | фаза 5: computed styles + иконки |
| Скриншот недоступен | нет дисплея | гистограмма + evaluate_js-смоук |

## Gotchas

- **Бот-щит:** curl отдаёт заглушку; CSS по прямым путям часто отдаётся; DOM/computed — только живой браузер.
- **Квантизация гистограммы** сливает мелкие акценты — снимать в полном разрешении, сверять по hue.
- **Не копировать баги референса** (светлый попап на тёмной теме); **офлайн:** никаких CDN — всё инлайн/локально.
- **Токены — в CSS-переменные**, не hex по файлу: правка стиля = правка таблицы.

## Available scripts

- `design_teardown.py css <файл>` — токены из CSS в таблицу.
- `design_teardown.py histogram <png> [-n 14]` — палитра скриншота (нужен ImageMagick `convert`).
