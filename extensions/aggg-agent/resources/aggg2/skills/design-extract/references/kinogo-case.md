# Кейс: копирование стиля kinogotv.cc → GUI-панель (проверено живьём)

Полный цикл двух проходов: первый проход «в стиле», второй —
точное копирование по фидбеку «не очень точно + не хватает иконок».

## Что снималось с референса

### Слой 2: computed styles (живой браузер)

CSS-файл врал: `.logotype` в CSS скрыт (`display:none`) — в рендере
виден. Снятые computed styles дали точную картину:

- `.header-in`: чёрный бар, height 44px, padding 8px, фикс сверху;
- `.login-btns a`: прозрачный фон, `#e0dfdc`, подчёркивание;
- `.footer`: `#2b2b2b`, radius 5px;
- `.nav-menu a`: прозрачный фон, `#e0dfdc`, 13px, underline.

### Слой 3: гистограмма скриншота

Скриншот сайта + `convert -colors N -unique-colors txt:` — палитра
подтвердила токены. Та же техника использовалась для ПРОВЕРКИ нашего
результата: до фиксов гистограмма окна показывала только серые тона
(= цвета не отрисовались, WebKitGTK+NVIDIA), после — золото `#FAD771`,
teal `#2B8E71`, циан бейджа `#2897AC` на месте.

## Слияние с лучшими практиками

| Референс | Что взяли из индустрии поверх |
|---|---|
| тёмная тема `#000` | анти-halation (не чистый белый текст), focus-visible ринги |
| иконки Font Awesome | инлайн-SVG-спрайт Lucide (SVG > icon-font, офлайн, currentColor) |
| `<select>` у референса | сегмент-контрол (паттерн eleken: 2-5 взаимоисключающих опций) |
| стеклянные эффекты — | НЕТ: на WebKitGTK+NVIDIA backdrop-filter/blur дают артефакты (Orrery playbook) |

## Второй проход по фидбеку

«Не очень точно + не хватает иконок» → что добавлено:

1. computed styles вместо только CSS (хедер-бар 44px, подвал);
2. фирменный бейдж с анимированным градиентом (самая узнаваемая
   деталь kinogo);
3. 15 инлайн-SVG иконок (power, shield, globe, terminal, zap,
   server, layers, clock, search, trash, wifi, toggle, play,
   plus, x, rotate);
4. подвал `vpn-gui · sing-box · TUN-туннель`.

Проверка после прохода: гистограмма (акценты на месте) + E2E-смоук.

## Уроки

- CSS-файл — старт, computed styles — истина, гистограмма — приёмка.
- Модель без картинок ≠ слепой: числа (токены, пиксели) заменяют взгляд.
- Фидбек «не похоже» — фаза цикла: глубже слой извлечения, а не
  подгонка вслепую.
- Стиль референса + лучшие практики + ограничения платформы — все три
  слоя обязательны; пропуск платформы даёт красивый, но сломанный рендер.
