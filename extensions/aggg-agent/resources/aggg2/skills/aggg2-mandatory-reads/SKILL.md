# Обязательное чтение контекста AGGG2.0

Канон, по которому работает весь воркспейс AGGG2.0. Читать **тирами,
не все сразу**: Tier A — всегда, Tier B — по типу задачи. Все разом =
перегруз: агент не дочитывает, следование падает. Не отвечать по памяти —
файлы правятся, содержимое меняется.

**AGENTS.md читать НЕ нужно** — он уже в контексте сессии (instructions
харнеса). Карта скиллов/агентов/зеркал — оттуда.

## Тир-чтение (какой файл когда)

| Тир | Файлы | Когда читать |
|---|---|---|
| **A — всегда** | `CYCLE.md` — цикл работы (фазы 0-8, гейты, боевое крещение, чекпоинты); `CLAUDE.md` — персона, веб-ресёрч, кодинг, стиль объяснений; **+ скилл `aggg2-persona`** — как говорить (тон, структура ответа) | каждая задача, целиком, даже мелочь |
| **B — по типу** | `docs/canon/CAMOUFOX.md` — веб-ресёрч; `DB-FIRST.md` — база/аудит; `AGENT-LSP.md` — код: типы/ссылки/правки; `CODE-GRAPH.md` — дифф/ревью; `SETUP.md` — установка; `WIKI.md` — Wiki/; `skills.sh.md` + `SKILLS-LOCAL.md` — скиллы; `SEMBLE.md` — смысловой поиск | свой на задачу, ДО действий в этом домене |

Tier A — всегда. Tier B — все файлы, которые затрагивает задача (код +
дифф → AGENT-LSP.md И CODE-GRAPH.md). Не читать весь Tier B «на всякий
случай» — progressive disclosure: ровно свой набор.

## Скиллы по типу задачи (читать ПЕРЕД задачей — обязательно)

Файлы выше — база; дальше — скилл под тип задачи, ДО начала работы
(progressive disclosure: не все сразу, а свой на задачу). **Полные списки:
обязательные (17) и по запросу (29) — в AGENTS.md (уже в контексте)**,
триггер-фразы владельца — в harness/core.txt п.3. Здесь — суть:

- **Обязательные по типу:** `nodumb` (дорогие развилки), `ask-nodumb`
  (продукт/UX), `changelog-discipline` (изменения кода), `system-feedback`
  (после действий), `fable-judge` (после «готово»), `fable-loop`
  (многошаговое с оркестрацией), `fable-method` (цикл решений),
  `code-review` (ревью диффа), `battle-test` (стресс-тест цифрами),
  `task-cycle` (рабочий цикл), `db-first-search` (вопросы по воркспейсу),
  `web-research-camoufox` (задачи с выбором), `code-search-ladder`
  (поиск по коду), `semble` (смысловой поиск), `skill-search`
  (поиск скиллов).
- Их игнорирование на задаче соответствующего типа = нарушение
  (nodumbmode, собраны из реальных фейлов).

## Workflow

0. **Загрузить `aggg2-persona`** — как говорить с владельцем (тон,
   объяснения слоями, результат первым, визуальная подача). Скилл — всегда,
   до общения, вместе с каноном: канон определяет ЧТО делать, persona — КАК.
1. Прочитать **Tier A целиком** (Read tool): `CYCLE.md`, `CLAUDE.md` —
   даже если «помнишь, что там». AGENTS.md — не читать (в контексте).
2. Прочитать **Tier B по типу задачи** (таблица выше) — ДО действий в этом домене.
3. Прочитать скилл под тип задачи — обязательно.
4. Выдать **канон-чек** — обязательный артефакт: таблица «файл → прочитан →
   1 главное правило из него». Без него следование не проверяемо: юзер должен
   видеть, что канон реально прочитан, а не продекларирован.
5. Дальше работать строго по правилам из файлов:
   - веб-ресёрч — **первое действие** при неизвестности/выборе, не последнее;
   - вопрос про содержимое воркспейса → **сначала поиск в базе**
     (`db/aggg2.db`, `db/sherpa-voice.db`, `db/research.db`), потом ответ;
   - выводы и находки ресёрча → в `db/research.db` (`findings.py add ...`).
6. Если файл недоступен или путь изменился — **остановиться и сообщить**,
   не продолжать по памяти.

## Gotchas

- **Канон-чек обязателен** (шаг 4): таблица «файл → прочитан → 1 главное
  правило». Пропуск = скилл не выполнен.
- **Тиры не отменяют Tier B** — задача про код без AGENT-LSP.md/CODE-GRAPH.md
  = нарушение; при этом читать ровно свой набор, не весь канон.
- **Не кэшировать содержимое файлов между сессиями** — они живут, правятся.
  Читать заново при каждом срабатывании скилла.
- **Скачанный сторонний скилл → СРАЗУ в `quarantine-skills/`** (карантин):
  не оставлять в рантайм-каталогах; установка из карантина — с согласия
  владельца.
- Канон скилла — `$AGGG2_ROOT/skills/aggg2-mandatory-reads/` (корень: маркер
  `VERSION` или `$AGGG2_ROOT`). В зеркалах относительные пути `../../` ломаются
  — указывать через `$AGGG2_ROOT/*.md`. ⚠️ Абсолютных путей в коде/доках нет.
- Корень не определяется (нет `VERSION`/`db-tools/`) — сообщить, не выдумывать.
