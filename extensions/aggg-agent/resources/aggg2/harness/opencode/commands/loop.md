Загрузи скилл `loop` ($AGGG2_ROOT/skills/loop/SKILL.md, корень — маркер
VERSION или $AGGG2_ROOT) и работай в режиме цикла.

Формат вызова: /loop N M промт. N — число витков (дефолт 5), M — лимит
минут (суффикс m/h), промт — задача/цель. Если аргументов нет — продолжи
с последнего чекпоинта: `findings.py search loop`.

Правила скилла обязательны: каждый виток — полный CYCLE + находка +
чекпоинт в research.db, следующий виток — с новым углом; стоп — только
по критериям (N/M/критерий готовности/2 витка без прогресса).
