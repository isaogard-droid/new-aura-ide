## Порядок любой задачи (цикл CYCLE)

0. Канон прочитан: скилл `aggg2-mandatory-reads` — AGENTS+CYCLE+CLAUDE всегда, остальные по типу задачи; после чтения — канон-чек (файл → главное правило).
1. Переосмысление: саммари запроса одной-двумя фразами (задача + цель). Не совпадает с буквой — уточни до действий.
2. База: сначала `findings.py search` (research.db) + `search.py` (проектные базы) — «мы это уже разбирали». Вопрос «найди код, который…» — лестница: semble.search (смысл, терминами дока) → db-tools (структура) → agent-lsp (символы); точное имя — сразу LSP; keyword — db-tools FTS, не semble; греп/read вслепую = нарушение.
3. Веб-ресёрч в Camoufox — ПЕРВОЕ действие, до кода и до ответов. Продолжается весь процесс, до конца задачи. Интернет = источник истины.
4. План для нетривиального: критерий готовности, что делаем, что НЕ делаем.
5. Действие: код пишется через базу (DB-FIRST), не с головы.
6. Проверка: QA (ruff/semgrep/тесты — свой аналог для языка), живьём где можно.
7. Находки: выводы ресёрча — в research.db (`findings.py add`), иначе знание теряется.
8. Отчёт: коротко, результат первым. Объяснять как динозавру, если просят (аудитория → слои → аналогия → проверка понимания; визуально — таблицы/списки, не стеной — CLAUDE.md «Как объяснять»).

## Императивы (не рекомендации)

- КАНОН ПЕРВЫМ: перед любой работой в AGGG2.0 — скилл aggg2-mandatory-reads (AGENTS+CYCLE+CLAUDE всегда, остальные по типу задачи); после чтения — канон-чек (файл → главное правило).
- ВЕБ-РЕСЁРЧ ПЕРВЫМ: перед любым ответом/кодом с выбором или неизвестностью — `web_search` в Camoufox, первоисточники, 2+ независимых источника на ключевой факт. НОРМАТИВ: МИНИМУМ 10 источников на любую задачу (справка/факт — 10; решения/выборы — 30-50, docs/canon/CAMOUFOX.md). «Подумал» без поиска = догадка.
- БАЗА ДО КОДА: вопросы по содержимому AGGG2.0/sherpa-voice — сначала db-tools (search/symbol/calls) и findings.py, потом чтение файлов. Ориентация в коде — карта первой (MCP repo_map / db-tools/repomap.py); связи файлов — search.py --calls/--imports; «где лежит» по всем базам — search_all (MCP/CLI).
- НЕ ОТВЕЧАТЬ С ГОЛОВЫ: факт без проверки = гипотеза, помечай «проверить», не выдавай за истину.
- СКИЛЛЫ НА КАЖДУЮ ЗАДАЧУ: nodumb (до дорогих развилок), ask-nodumb (продуктовые задачи), system-feedback (после действий — понятно ли юзеру), changelog-discipline (изменения кода). Для нетривиального многошагового — fable-method, с оркестрацией — fable-loop, после заявленного «готово» — fable-judge.
- ПРОДАКШЕН-ПЕРВЫМ: решение «как делать» — не из головы: сначала как это делают в индустрии (web search), потом по индустрии. Критерий готовности: «так делают все», а не «я так придумал».
- КОД: типы/скоуп/все ссылки — agent-lsp (не греп); ревью диффа — code-review-graph; после правок — диагностика и QA.
- СЕКРЕТЫ: только плейсхолдеры (YOUR_API_KEY), даже в research.db.
