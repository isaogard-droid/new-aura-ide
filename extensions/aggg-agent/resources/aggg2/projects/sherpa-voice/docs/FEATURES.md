## Экспорт в MD/PDF

В меню действий пункт `[3] 💾 Экспорт` сохраняет результат в
`~/sherpa-voice/exports/transcript_<дата-время>.md` и `.pdf` (PDF — если
установлен reportlab и найден шрифт с кириллицей; иначе — только MD, с
честным сообщением). В экспорт включаются уже сгенерированные разделы:
Саммари, Ответ и Кодинг-промт (если их делали). Экспорт не требует
ключа DeepSeek.

## Автоулучшение текста (знаки препинания, смысл)

Сразу после распознавания текст автоматически пропускается через DeepSeek
(если ключ в `.env`): расставляются знаки препинания и заглавные буквы,
исправляются **только очевидные** ошибки распознавания, восстанавливаются
явно усечённые слова («смер» → «смерть»), убираются слова-паразиты и
механические запинки. Числа и иностранные слова, произнесённые русскими
буквами, переводятся в цифры/латиницу («сикси севен эйт» → «6 7 8»), но
только при полной уверенности. Промпту ЗАПРЕЩЕНО выдумывать слова и
детали — не уверен, оставляет как есть (без догадок). В буфер обмена и в
меню действий попадает уже исправленный текст:

```
[text] смер если так дело пойдёт ну вот не знаю
[ai] Улучшаю текст (знаки препинания, смысл)…
[text исправлено] Смерть, если так дело пойдёт, не знаю.
```

Отключить: `DEEPSEEK_AUTO_POLISH=0` в `.env`. Без ключа — как раньше,
сырой текст.

## Кнопки-действия через DeepSeek (Задачи / Саммари / Ответить)

После распознавания консоль предлагает действия с текстом:

```
[ai] Действия:  [0] ✅ Задачи  [1] 📋 Саммари  [2] 💬 Ответить  [3] 💾 Экспорт  [4] 💻 Кодинг-промт  [5] 🧂 Подмешка  [6] 📨 Telegram  [7] 🔍 История  [8] 📅 Итог дня  [9] 🏷 Теги  [Enter] продолжить
```

- `0` — задачи (action items) из записи: только дела, по одному на строку,
  с глаголом («починить отправку», «заказать клавиатуру»). Сроки и
  исполнители добавляются, только если названы в записи. Нет задач —
  честно «Задач нет»
- `8` — итог дня: саммари записей за дату + отдельно «Задачи на день»
  (те же action items по всем записям дня, temperature=0)
- `1` — пересказ записи (2–5 предложений) + ключевые мысли списком
- `2` — ответ на запись как на голосовое сообщение (текстом, без ввода вопроса)
- `3` — экспорт в MD/PDF (работает и без ключа DeepSeek)
- `4` — кодинг-промт: озвученная задача превращается в ТЗ с чек-листом для
  агента (ресёрч первым делом — как это делают в проде, тесты, критерии
  готовности; без выдуманных сценариев)

Нужен ключ DeepSeek в `.env` рядом со скриптом (файл создаётся при установке,
ключ вставляете туда сами — не коммитьте его):

```
DEEPSEEK_API_KEY=sk-...
DEEPSEEK_MODEL=deepseek-v4-flash
```

Модель по умолчанию `deepseek-v4-flash` (актуальная по документации DeepSeek;
старое имя `deepseek-chat` убрали). Без ключа кнопки 0/1/2/4 не работают
(с понятным сообщением) — распознавание работает как раньше.

## Сессии (контекст как в OpenCode)

DeepSeek помнит диктовки дня: контекст хранится в сессиях
(`~/.cache/sherpa-voice/sessions/<id>.json`) — можно продолжать, создавать
новые и возвращаться к старым.

```bash
./run.sh                       # автопродолжение последней сессии
./run.sh --new-session         # новая сессия (старая сохранится)
./run.sh --session <id>        # подключиться к конкретной
./run.sh --list-sessions       # список всех сессий
```

В меню `[s] 🗂 Сессия` — текущая сессия, список последних 10 (выбор
номером), новая / компакт сейчас.

Автокомпакт (паттерн OpenCode V2): при переполнении (~250K токенов)
старые ходы сжимаются в сводку, хвост 15K токенов дословно. Настройки —
env: `SESSION_COMPACT_TOKENS`, `SESSION_KEEP_TOKENS`, `SESSION_BUFFER`.
DeepSeek V4: контекст 1M токенов + кэш префиксов по умолчанию (история
дешёвая — cache-hit).

## Подмешка (`[5] 🧂` в меню)

Постоянный «хвостик»: текст, который добавляется в конец каждого результата —
улучшенного текста (до записи в буфер и историю), саммари, ответа и
кодинг-промта. Хранится в каталоге настроек (`mix.txt`, см. «Настройки»)
и переживает перезапуски.

Подменю: `[1] 📖 Показать` (текст с видимыми границами), `[2] ✏️ Изменить`
(многострочный ввод: Enter — новая строка, пустая строка — закончить;
вписанный текст включается сразу), `[3] 🔄 Вкл/выкл`, `[4] 🗑 Очистить`.
Статус (вкл/выкл) виден в главном меню, путь к файлу — в строке подменю.
Подменю работает по принципу «одно действие — один заход»: после кнопки
сразу возврат в меню действий.
Запасной путь — ручная правка `mix.txt` (первая строка `ON`/`OFF`, дальше
текст; пустые строки внутри консольного ввода не сохраняются — они
завершают ввод, такие пробелы вставляются только правкой файла); подменю
перечитывает файл на каждом шаге и подхватит правку сразу.

Подмешка — механическая приписка, на модель не влияет. Если нужен текст,
меняющий поведение модели («отвечай кратко») — это отдельный механизм
(подача в промпт), здесь не реализован.
