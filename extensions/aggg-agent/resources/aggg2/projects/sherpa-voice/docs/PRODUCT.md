## Цель / назначение

Лёгкий локальный транскрайбер «нажал Enter, сказал фразу — получил текст»
для слабых машин: микрофон → распознавание → текст (и далее: полировка,
экспорт, Telegram). Распознавание локальное через sherpa-onnx (русские
модели), без облака, старт <1 с, RAM ~300 МБ.

## Фичи (что умеет)

| Область | Возможности |
|---|---|
| Распознавание | 3 модели: GigaAM v3 transducer (230МБ, default, + hotwords), offline Zipformer int8 (74МБ), streaming (29МБ); VAD; запись с устройства или из файла (`--file`) |
| Hotwords / словарь | Редкие слова («црг», «гигаам») распознаются по словарю; learning-loop сам учит новые термины из транскриптов (hotwords.py, анти-мусор) |
| Полировка | Автоулучшение текста: знаки препинания, смысл; «широкий текст» для транскрипций; санитизация (полировка через DeepSeek) |
| Кнопки-действия | DeepSeek-кнопки под текстом: Задачи / Саммари / Ответить (сгенерировать ответ по контексту) |
| Сессии | Контекст как в OpenCode: теги, день-саммари, история, поиск по истории |
| Подмешка | `[5] 🧂` в меню: копилка готовых фрагментов — вставить в текущий текст |
| Экспорт | MD/PDF автоматически (`--auto-export`) или вручную; публикация транскрипта |
| Telegram | `--telegram-daemon`: приём голосовых из Telegram в систему (перевод → текст → ответ); кнопки под ответом; управление из Telegram; `/ping` — healthcheck «бот жив» (ответ `pong 🏓`) |
| Интеграции | DeepSeek (полировка/кнопки), редактор пользователя (из конфига), буфер обмена, уведомления |
| Режимы | `--once` (хоткей, одна запись), `--silence N` (фоновый, стоп по тишине), `--list-devices`, единственный инстанс |

## Интерфейс (экраны/меню)

Терминальный UI (пакет chat/ + ui_utils.py): меню действий (номера [1]-[6]:
история, подмешка, Telegram и т.д.), поле ввода, кнопки-действия под
текстом. Настройки: `.env` + каталог настроек (токен Telegram, модель,
устройство). При первом запуске — запрос токена/настроек (меню).

## Техническая карта

| Модуль | Роль |
|---|---|
| `transcribe.py` | CLI: запись, распознавание (sherpa-onnx), флаги |
| `chat/` | Диалог/меню (пакет: commands/polish/history/mix/publish/vocab/actions/menus): полировка, подмешка, теги, саммари, публикация |
| `store.py` | Хранилище: история, сессии, подмешка, vocab/hotwords, дневная статистика |
| `ui_utils.py` | Настройки, буфер обмена, уведомления, единственный инстанс |
| `telegram.py` | Telegram-daemon: приём голосовых, отправка текста/рич-текста |
| `hotwords.py` | Learning-loop: пополнение vocab/hotwords из транскриптов |

## Решения и ограничения (что выбрано и почему — не переигрывать без причины)

- **Модели:** GigaAM v3 transducer (230МБ, default: качество WER ~4.4-4.7% +
  hotwords-словарь) / offline Zipformer int8 (74МБ) / streaming (29МБ).
  Модель качается автоматически в `models/` при первом запуске.
- **Декодер:** `decoding_method="modified_beam_search"` во всех ветках —
  та же скорость, что greedy, но стабильнее; замеры в
  `docs/experiments/hotwords-bench.md`.
- **Contextual biasing (hotwords через декодер) — ОТКЛОНЕНО** замером:
  эффект частичный, score 20 ломает текст. Работает только словарь/
  learning-loop (`hotwords.py`). Не возвращать без новых замеров.
- **Полировка/кнопки** — через DeepSeek API (ключ в настройках); без ключа
  приложение работает в режиме распознавания.
- **Подмешка** (`~/.cache/sherpa-voice/mix.txt`) — механическая приписка
  ПОСЛЕ генерации, на модель не влияет. Поведенческие инструкции в промпт —
  отдельный механизм, отклонён (пока).
- **Telegram-отправка:** единая `_tg_send_result` — rich при удаче, фолбэк
  на plain при ошибке или тексте >4000. Новые места отправки подключать
  только через неё.
- **История:** `~/.cache/sherpa-voice/history.md` (и `mix.txt`) — вне репо,
  в базе sherpa-voice.db через `--extra-files`.

## Не трогать / хрупкое

- **Сырой текст транскрипта** — хранится как есть, никуда не идёт; не
  «улучшать» при сохранении.
- **Слепые except в CLI-обвязке** (audio/транскрайбер) — осознанный стиль
  (S110, noqa с причиной), не менять на точечные без разбора.
- **Editor вызывается без shell=True** (`shlex.split`) — не возвращать
  `shell=True` (инъекции, semgrep).
- **Единственный инстанс** и пути кэша/моделей — не переносить в репо.
