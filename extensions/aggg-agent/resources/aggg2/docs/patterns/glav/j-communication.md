# J. КОММУНИКАЦИЯ И РАБОТА В ПАРЕ (агент/тим)

---

## 67. LEAD WITH ACTION, END WITH NEXT ACTION
**Принцип:** ADHD/операционный режим: первая и последняя строка полезны.
**Правило:** Что сделано → что нажать. Без вступлений и «если что пиши».
**Антипаттерн:** Эссе на 40 строк без команды/кнопки.
**Проверка:** Прочитал 1-ю и последнюю — понял статус и next step.

---

## 68. CODE/COMMITS CLEAN; CHAT CAN BE ROUGH
**Принцип:** В git — профессионально; в чате — можно по-человечески.
**Правило:** Нет мата/мусора в commit, PR, user-facing strings (если не бренд).
**Антипаттерн:** commit message «наебнулось пофиксил».
**Проверка:** git log пригоден для чужого глаза.

---

## 69. ONE CRITICAL QUESTION BEATS WRONG BUILD
**Принцип:** Неясный trigger бонуса (start vs purchase) → спросить, не угадать.
**Правило:** Один уточняющий вопрос на развилке денег/абуза.
**Антипаттерн:** Построил MLM, просили simple invite.
**Проверка:** Перед money feature есть явный product choice в чате/доке.

---

## 70. KEEP A PASSPORT OF THE SYSTEM
**Принцип:** Секреты, admin ids, product rules, paths — в одном известном месте.
**Правило:** passport/AGENTS/README ops section; обновлять при изменении.
**Антипаттерн:** «Где токен?» каждый раз по всей машине.
**Проверка:** Новый агент/дев находит admin id и DB path за <2 минуты.
