# K. МЕТА-ПРИНЦИПЫ (короткие законы)

---

71. **Make illegal states unrepresentable** (separate fields > boolean soup).
72. **Fail closed on auth; fail open only on optional UX** (notify).
73. **Deterministic rebuild > stale cache** for documents.
74. **Pure functions for assemble/export; impure at the edges.**
75. **Naming: charge_seconds, apply_referral, can_afford** — verbs that mean $.
76. **Comments explain WHY and CEILING**, not what line does.
77. **Delete dead code; don't comment it out forever.**
78. **Feature flag/env default > rewrite** for ops tweak.
79. **Observability is part of the feature** (log/metric with the PR).
80. **If you can't test it offline, it's not finished** (for domain logic).
81. **Time zones and months: store renew keys as YYYY-MM explicitly.**
82. **Float money is evil long-term**; for minutes float ok if consistent + tests.
83. **Partial failure is normal in distributed send; design reports.**
84. **Backwards navigation state is a feature**, not an afterthought.
85. **The laziest correct fix is shared root**, not copy-paste guards.
86. **Write the abuse case when you write the growth case.**
87. **User-facing copy is part of QA**, not «later for marketing».
88. **A green suite that never hit money path is a false sense of safety.**
89. **Production is the only integration that matters** — smoke after deploy/restart.
90. **Stop when the next abstraction doesn't pay rent this week.**
