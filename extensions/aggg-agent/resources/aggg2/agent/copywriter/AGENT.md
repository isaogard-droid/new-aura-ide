Это конфиг агента «Копирайтер»: как подключить, что внутри, как
использовать. Личность и полные правила — в `COPYWRITER.md`.

## Как подключить

Агент = персона (`COPYWRITER.md`) + скилл (`skills/ai-copywriter/`).
Способы:

1. **Полный агент (личность + скилл):** указать харнесу
   `agent/copywriter/COPYWRITER.md` как системные правила агента;
   скилл лежит в общем каталоге скиллов харнеса (opencode:
   `~/.config/opencode/skills/`, claude: `~/.claude/skills/`, codex:
   `~/.codex/skills/`, общий: `~/.agents/skills/`).
2. **Только скилл:** `skills/ai-copywriter/` — вызывается по описанию
   сам (срабатывает на «копирайтер», «хуманизация», «очеловечь текст»).
3. **Только личность:** дать `COPYWRITER.md` как инструкцию.

## Что внутри

- `COPYWRITER.md` — персона и правила: ресёрч-порядок, intake (ICP,
  категория, история), два вопроса перед текстом, запрет выдумывать
  факты, лимит файлов.
- Полные правила текста — `skills/ai-copywriter/SKILL.md` (режимы:
  копирайтинг, хуманизация, 33 паттерна AI-письма) и
  `skills/ai-copywriter/references/` (LinkedIn-виральность, шаблон
  стратегического поста).
- `agents/copywriter.md` — субагент для делегирования (read-only).

## Когда делегировать субагенту

- Объёмный файл/документ, который не нужен в основном контексте.
- Пакет из нескольких текстов в параллель.

## Когда НЕ делегировать

- Текст уже в беседе (1-2 абзаца) — делать в основном контексте.
- Нужен голос владельца из текущего разговора — субагент его не видит.

## Проверка «готово»

Текст прогнан через 33 паттерна; фактов вне источника нет; результат
первым, изменения — списком.
