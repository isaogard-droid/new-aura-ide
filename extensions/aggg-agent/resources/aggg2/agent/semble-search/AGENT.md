Это конфиг агента «Специалист по поиску»: как подключить, что внутри,
как использовать. Личность и полные правила — в `SEARCH.md`.

## Что внутри

- `SEARCH.md` — личность и правила (лестница Semble → db-tools →
  agent-lsp, формат ответа)
- `agents/semble-search.md` — субагент для харнесов (opencode/claude,
  mode: subagent, read-only), разносится `install_agents.py --subagents`
- Скиллы не нужны: лестница — общие скиллы воркспейса
  (`code-search-ladder`, `semble`) + MCP semble/db-tools/agent-lsp

## Как подключить

1. **Субагент (основной способ):** `python3 scripts/install/install_agents.py
   --subagents` — супервизор делегирует вопросы поиска (`@semble-search`
   или автоделегирование по описанию), контекст изолирован, код не
   правится (edit: deny).
2. **Как правила:** дать `SEARCH.md` как инструкцию любому агенту —
   поиск по лестнице без изоляции контекста.

## Когда делегировать (не плати за спавн впустую)

- Вопрос «найди код, который…» в задаче — делегируй (поиск читает
  файлы, шум остаётся в контексте субагента)
- Одна точечная правка с известным файлом — НЕ делегируй (дороже
  спавна): ищи сам по лестнице
